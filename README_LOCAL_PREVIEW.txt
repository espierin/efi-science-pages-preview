EFI Science Pages — local preview
=================================

1. Extract this complete ZIP archive to a folder on your computer.
2. Open 01-science-at-efi.html in a modern browser (Chrome, Edge, Firefox, or Safari).
3. Use the links in the pages to move through the prototype.

Important
---------
- Keep the assets folder next to the HTML files. It contains the committee portraits.
- This is a local prototype, not a live EFI website or a CMS package.
- Portraits are included for review only and require member approval before any public use.
- Internet is not required to view the prototype itself. ORCID links will open only when internet is available.

Included files
--------------
- Eight standalone EFI Science HTML pages
- Local portrait images used on the Scientific Committee page
- Content-maintenance guide and portrait source record
