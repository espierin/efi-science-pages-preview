# EFI Science pages — content and maintenance guide

These eight standalone HTML files are visual/content prototypes. They have intentionally embedded CSS so each can be reviewed or handed to the EFI web team independently. They are not production templates: the live implementation should use EFI’s CMS components, accessibility rules, navigation and authentication rather than copy/paste HTML.

## EFI editorial voice

Keep the content recognisably EFI: European, collegial, scientifically rigorous and connected to the everyday practice of histocompatibility and immunogenetics laboratories and transplantation. Prefer **“EFI members”, “European H&I community”, “scientific exchange”, “laboratories”, “annual EFI Conference”** and **“across Europe and beyond”**. Avoid corporate or campaign language such as “thought leadership”, “ecosystem”, “disruption”, “join the movement”, or generic claims of global leadership. Describe international partners precisely and do not imply endorsement or joint activity without confirmation.

## Publishing rules

1. Every time-sensitive item must have an owner, a publication date, an explicit deadline/date, and a removal/review date.
2. Do not publish placeholders. If an event has no confirmed registration link, show a “details to follow” status only if the event itself is confirmed.
3. Use plain English summaries; link to source documents for technical detail.
4. Mark member-only material clearly before the click. Do not create a second access mechanism outside EFI’s existing login.
5. Maintain a brief reviewed archive rather than leaving expired calls or recordings on landing pages.
6. Use image alt text, descriptive link text, heading order, high contrast and accessible PDFs/documents.

## Scientific Committee: About Us profile data

The `02-scientific-committee.html` prototype uses the members published on EFI’s current committee page. Names and countries must be checked at launch because terms and composition change.

For each member, obtain written approval for:

- preferred name, title, role and term dates;
- institution, country and professional headshot;
- a 40–60 word biography written in third person;
- 3–5 research-interest tags selected from the EFI theme taxonomy;
- optional ORCID URL (`https://orcid.org/0000-0000-0000-0000`), not a manually typed identifier;
- optional institutional profile link.

ORCID should be optional. It is useful for a scientific audience, but EFI should link only to an ORCID URL supplied or explicitly verified by that member. Do not infer ORCID records from names.

## Landing-page editorial model

Keep “Now in Science” to three or four items. A good monthly selection is: one event/call, one committee or partner activity, one high-value resource/publication, and one early-career opportunity. Replace rather than endlessly add cards.

Each theme page should have a 100-word overview, one named editorial contact, current related items, and a link to the contribution route. Themes are an editorial taxonomy, not new committee structures.

## Suggested operating workflow

1. At the SC meeting, decide the next quarter’s priority activities and nominate a content source for each.
2. The editorial lead prepares concise draft copy using an agreed 1-page content form.
3. A relevant SC member checks scientific accuracy; EFI Office checks dates, links, style and accessibility.
4. Publish, set the review/removal date, and log the source material.
5. At month-end, remove or archive expired content and refresh the landing page.

## Minimum viable launch

Launch the Science landing page, Scientific Committee About Us page, webinars/events, awards/early-career page and Get Involved route first. Add themes, publications/resources and collaborations once each has a named owner and initial verified content. This protects quality and makes the site sustainable.
